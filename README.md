# E-commerce Sales Dashboard | Power-BI
Interactive Power BI dashboard analysing e-commerce sales performance with actionable business insights using DAX, Power Query, and data visualisation.

## Project Overview
This project is an interactive E-commerce Sales Dashboard built using Power BI to analyse sales performance and provide meaningful business insights. The dashboard enables users to monitor key performance indicators (KPIs), identify sales trends, evaluate product category performance, and understand customer purchasing behaviour through interactive visualisations and filters.

## Objectives
The objective of this project is to transform raw e-commerce sales data into a visually intuitive dashboard that supports data-driven decision-making. By analysing key metrics such as sales, profit, quantity sold, customer segments, and regional performance, the dashboard helps identify growth opportunities, track business performance, and uncover actionable insights for improving sales strategies.

## Dashboard Features
- KPI cards displaying:
  - Total Sales Amount
  - Total Quantity Sold
  - Total Profit
- Average Order Value (AOV)
- Quarter-wise filter to analyse performance across different quarters.
- State-wise profit analysis to identify the most profitable states.
- Category-wise quantity distribution using a doughnut chart.
- Monthly profit trend visualisation highlighting profitable and loss-making months.
- Highest-paying customers analysis.
- Payment mode distribution (COD, UPI, Debit Card, Credit Card, EMI).
- Profit by product sub-category to identify the best-performing products.

## Key Business Insights
- Maharashtra generated the highest profit among all states.
- Clothing accounted for the largest share of total quantity sold (63%).
- Cash on Delivery (COD) was the most preferred payment method, contributing 44% of total orders.
- Printers generated the highest profit among all product sub-categories.
- Monthly profit varied significantly, with strong performance in January, February, March, and November, while May and July experienced  losses.
- Harivansh emerged as the highest-paying customer based on total purchase value.
